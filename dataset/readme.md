# 📊 Datasets

Este directorio contiene los conjuntos de datos (**datasets**) utilizados en distintos notebooks para **análisis exploratorio**, **modelado** y **prácticas de ciencia de datos**.

Los archivos se encuentran principalmente en formato **CSV**, lo que permite cargarlos y manipularlos fácilmente utilizando herramientas comunes como:

- **Python**: `pandas.read_csv()`
- **R**: `read.csv()`

## 📁 Contenido del directorio

Dentro de este directorio se incluyen datasets clásicos y ampliamente utilizados en el aprendizaje y la práctica de data science, entre ellos:

- **Titanic**: datos de pasajeros utilizados para tareas de clasificación y análisis exploratorio.
- **Zomato**: información relacionada con restaurantes, ubicaciones y calificaciones.
- **Churn**: datasets orientados al análisis de abandono de clientes.
- Otros datasets utilizados para distintos ejercicios y ejemplos prácticos.

Cada dataset puede ser utilizado de forma independiente según el notebook o proyecto correspondiente.
